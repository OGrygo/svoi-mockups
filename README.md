# Свої — мокапи для клієнтів

Демо-мокапи продукту «Свої» під конкретних клієнтів, опубліковані з їхнього дозволу. Люди й більшість цифр на екранах — демо.

- `komuna.html` — «Комуна жіноцтва»
- `nabik.html` — «НаБіК», закрито паролем (вміст зашифровано)
- `ludanova.html` — простір психологині Анастасії Луданової

Оновлення: перезібрати `python3 -I prototype/v2/build.py <slug>` у Project X, скопіювати збірку сюди з мета-тегом `noindex`, закомітити й запушити від OGrygo.

Якщо в мокапі приватні дані клієнта, замість копіювання закрити його паролем: `node prototype/v2/tools/lock.mjs clients/<slug>/svoi-<slug>.html ../../svoi-mockups/<slug>.html <пароль>`. Відкрити можна паролем або персональним посиланням `<url>#k=<пароль>`.
