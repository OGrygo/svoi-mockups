# Свої — мокапи для клієнтів

Демо-мокапи продукту «Свої» під конкретних клієнтів, опубліковані з їхнього дозволу. Люди й більшість цифр на екранах — демо.

- `komuna.html` — «Комуна жіноцтва»

Оновлення: перезібрати `python3 -I prototype/v2/build.py <slug>` у Project X, скопіювати збірку сюди з мета-тегом `noindex`, закомітити й запушити від OGrygo.
